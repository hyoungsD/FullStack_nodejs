 * multer:
 - 파일 업로드를 처리하는 미들웨어


 * bcryptjs:
  - 비밀번호 해싱


* jsonwebtoken:
  (jwt.io)
 - Json Web Token (JWT)
 - 로그인 정보를 서버에 저장하지 않고, 토큰으로 인증하는 방식
 - 1. 서버가 상태를 저장하지 않아도 됨 (Stateless)
  = 기존: 세션 → 서버가 로그인 정보 저장
  = JWT: 토큰만 주고 서버는 저장 안 함
 - 2. 로그인 유지 (인증)
  = 로그인 성공 시 토큰 발급
  = 이후 요청마다 토큰만 보내면 로그인 상태 확인 가능
 - 3. 확장성 좋음
  = 여러 서버(마이크로서비스)에서도 동일하게 인증 가능
  = 세션 공유 필요 없음
